Dan badge artwork from Mania Tracker (https://github.com/aleju03/mania-hub, public/images/dans), unchanged.
reform = 4K (1-10, alpha-kappa), ln = 4K LN (1-17), 7k = 7K (plain = regular, ln- = LN), 6k = 6K (plain = regular, ln- = LN).
File suffixes: -low = "--", -mid-low = "-", none = mid, -mid-high = "+", -high = "++".
According to the source, the 6K glyphs are traced from the dan course backgrounds (Arkman regular, sunnyxxy LN)
and the 7K ladder is the JinJin 7K courses: the course marks belong to their course authors.
